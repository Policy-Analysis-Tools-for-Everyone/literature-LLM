# Data handling for this private repository

**Suitable repository content:** agent instructions, transparent method descriptions, bibliographic citation metadata, synthesis written in our own words with source citations, and abstract methodological inventories.

**Keep in approved controlled storage:** original Scopus CSVs with bulk abstracts; publisher PDFs where redistribution rights have not been established; respondent/participant records; consent forms containing identifiable information; raw classroom observation notes; interview transcripts; any UCL data whose use/storage exceeds the approved protocol.

The `.gitignore` reduces accidental additions; it is **not a security boundary**. A manual GitHub web upload or `git add -f` can bypass it. Review every commit for restricted content. Private repository access does not by itself authorise licensed-article redistribution or research participant data processing.

When ingesting a source, use its DOI/permalink and a secure local copy; keep the source note bibliographic/analytical, not a substitute copy of the article.
