# References and citation integrity

The project is moving towards a **UK Harvard author–date** style. See [Harvard house standard](harvard-standard.md) for in-text citations, original page/table locators, article-number handling, DOI checks and venue-specific override rules.

The [eighteen-paper DOI index](source-index.md) identifies the current working corpus, but is **not yet a fully checked Harvard reference list**. Author lists, volume, issue, page ranges and publication statuses must be verified against each original publication before generating final prose.

Future: verified BibTeX/CSL JSON generated from source publications and consistently rendered to the required journal or UCL style. Do not fabricate missing fields or use a DOI as evidence of claim support.
